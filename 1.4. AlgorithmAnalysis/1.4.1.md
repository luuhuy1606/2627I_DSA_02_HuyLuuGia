1. 
for (int i = 10; i < n + 5; i += 2) op();
- Giải thích: Vòng lặp chạy từ 10 đến n + 5 với bước nhảy 2. Số lần lặp xấp xỉ ((n + 5) - 10) / 2 = (n - 5) / 2.
- Xấp xỉ (~): ~ 1/2 n
- Big Theta (Θ): Θ(n)

2. 
for (int i = 1; i <= n * n * n; i *= 2) op();
- Giải thích: i nhận các giá trị 2^k <= n^3 => k <= 3*log2(n). Số lần lặp là floor(3*log2(n)) + 1.
- Xấp xỉ (~): ~ 3 log2(n)
- Big Theta (Θ): Θ(log n)

3. 
for (int i = 0; i < n; i++)
    for (int j = 0; j < 100; j++) op();
- Giải thích: Vòng lặp ngoài chạy n lần, vòng trong chạy cố định 100 lần. Tổng số lần chạy chính xác là 100n.
- Xấp xỉ (~): ~ 100n
- Big Theta (Θ): Θ(n)

4. 
for (int i = 0; i * i < n; i++)
    for (int j = 1; j < n; j *= 3) op();
- Giải thích: Vòng ngoài chạy sqrt(n) lần (do i^2 < n). Vòng trong nhân 3 mỗi bước nên chạy log3(n) lần. Tổng số lần là sqrt(n) * log3(n).
- Xấp xỉ (~): ~ sqrt(n) * log3(n)
- Big Theta (Θ): Θ(sqrt(n) * log n)

5. 
for (int i = 0; i < n; i++)
    for (int j = 1; j < n; j *= 2) op();
- Giải thích: Vòng ngoài chạy n lần. Vòng trong nhân đôi mỗi bước nên chạy log2(n) lần. Tổng số lần là n * log2(n).
- Xấp xỉ (~): ~ n log2(n)
- Big Theta (Θ): Θ(n log n)

6. 
for (int i = 0; i < n; i++)
    for (int j = 0; j < 100; j++)
        for (int k = 0; k < n; k++)
            for (int l = k; l < n; l++) op();
- Giải thích: 
  + Hai vòng ngoài chạy: 100 * n lần.
  + Hai vòng trong: Với mỗi k, l chạy từ k đến n-1 (n - k lần). Tổng = n(n + 1) / 2.
  + Tổng số lần: 100n * (n(n + 1) / 2) = 50n^3 + 50n^2.
- Xấp xỉ (~): ~ 50n^3
- Big Theta (Θ): Θ(n^3)
